# 意图链路

## 什么是意图链路？

语音从采集到响应的完整处理流水线。设备和用户只感知到"说话→应答"，背后经历了 5 个环节的处理。

## 处理流程

```mermaid
flowchart LR
    Audio[音频] --> ASR["ASR：阿里云语音识别"]
    ASR --> Text[文本]
    Text --> LLM["LLM：DeepSeek v4-flash"]
    LLM --> Intent["Intent：函数调用"]
    Intent --> Result[结果文本]
    Result --> TTS["TTS：硅基流动 CosyVoice"]
    TTS --> Speech[语音输出]
```

### 环节 1：ASR（自动语音识别）

- 引擎：AliyunStreamASR
- 输入：设备采集的音频流
- 输出：文本字符串
- 配置：阿里云 appkey + AK/SK

### 环节 2：LLM（大语言模型）

- 引擎：OpenAILLM → DeepSeek v4-flash
- API：兼容 OpenAI API 格式
- 系统提示：`"我是一个叫小智的台湾女孩，说话机车，声音好听，习惯简短表达。"`
- 输出：意图判断 + 函数调用参数

### 环节 3：Intent（意图执行）

- 引擎：function_call
- 匹配：LLM 根据函数描述决定调用哪个插件
- 执行：调用对应 Python 函数
- 输出：函数结果文本

### 环节 4：TTS（文本转语音）

- 引擎：CosyVoiceSiliconflow
- 模型：FunAudioLLM/CosyVoice2-0.5B
- 音色：定制语音克隆（private_voice）
- 输入：回复文本
- 输出：音频数据

### 环节 5：播放

- 通过 WebSocket 下发音频到设备
- 设备扬声器播放
