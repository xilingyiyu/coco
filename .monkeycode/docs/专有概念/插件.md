# 插件

## 什么是插件？

插件是 Python 函数模块，通过 `@register_function` 装饰器注册到系统中。LLM 在意图识别阶段根据函数描述和参数自动决定调用哪个插件。

## 注册机制

系统使用 `loadplugins.auto_import_modules("plugins_func.functions")` 自动扫描 `plugins_func/functions/` 目录下的所有 `.py` 文件，通过 `@register_function` 装饰器收集函数定义。

## Intent 配置

在 `.config.yaml` 的 `Intent.function_call.functions` 中列出启用的函数名。注意 list 类型直接覆盖（非递归合并），必须完整列出。

## Action 返回值策略

- **天气插件**: 使用 `RESPONSE` 直接播报，避免 LLM 擅自修改城市名称
- **微信/快递插件**: 使用 `REQLLM` 让 LLM 生成自然语言回复
- **点歌插件**: 使用 `RECORD` 只记录调用，音频直接通过 TTS 流播放
