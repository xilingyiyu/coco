# 设备

## 什么是设备？

代表一台连接到小智智控台的 ESP32 硬件设备。每台设备通过唯一的 MAC 地址标识，通过 WebSocket 与服务端通信，实现语音交互。

| 连接端点 | `ws://47.108.153.232:8000/xiaozhi/v1/` |

## 关键特征

- 通过 WebSocket 长连接维持在线状态
- 内置麦克风采集语音，扬声器播放 TTS 音频
- LCD 屏幕显示表情和状态
- 支持 OTA 固件升级（端口 8003）
- 支持视觉分析（摄像头）

## 交互流程

```
用户说话
  → 设备采集音频 → WS 上传
  → ASR 识别为文本
  → LLM 理解意图 + 调用插件
  → TTS 合成语音 → WS 下发
  → 设备扬声器播放
```

## 绑定步骤

1. 设备启动后自动向智控台注册（MAC 地址识别）
2. 在智控台 Web 端手动审批设备绑定到指定智能体
3. 绑定后设备即可通过 LLM 驱动的角色（小智）与用户对话

## OTA 升级

- 端点: `47.108.153.232:8003`
- 路径: `/xiaozhi/ota/`
- 固件由智控台 Web 端上传管理
