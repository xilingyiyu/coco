# 设备

## 什么是设备？

代表一台连接到小智智控台的 ESP32 硬件设备。每台设备通过唯一的 MAC 地址标识，通过 WebSocket 与服务端通信，实现语音交互。

**当前已绑定设备**:
- MAC: `80:b5:4e:df:d1:b8`
- 型号: `bread-compact-wifi-lcd`

## 关键特征

- 通过 WebSocket 长连接维持在线状态
- 内置麦克风采集语音，扬声器播放 TTS 音频
- 支持 OTA 固件升级
- 支持视觉分析（摄像头）

## 连接方式

- WebSocket 端点: `ws://47.108.153.232:8000/xiaozhi/v1/`
- 智控台 Web: `xiaozhi.xilingyiyu.cn`

## 生命周期

1. 设备上电 → WiFi 连接 → WebSocket 连接
2. 用户说话 → 音频流上传 → ASR 识别
3. LLM 处理 → Intent 执行 → TTS 合成
4. 音频下发 → 扬声器播放
